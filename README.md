# Collage Web App

Eine einfache, vollständig lokale Collage-App für iPhone/Safari.

## Funktionen
- 2, 4 oder 6 Bilder
- Bildauswahl aus der iPhone-Fotomediathek
- Canvas-Ausgabe 1200 × 1200 px
- 10 px grauer Abstand zwischen den Bildern
- Bilder werden automatisch mittig zugeschnitten
- Mehrere Texte möglich
- Text verschieben, drehen, Größe/Farbe/Schriftstärke ändern
- Als JPG speichern
- Über iOS Share Sheet teilen
- Keine Server-/Cloud-Verarbeitung der Bilder

## Start
`index.html` in einem Browser öffnen oder über GitHub Pages hosten.
